# Dump Truck
Right-click bag items at the auction house to queue them, each one gets priced at the current lowest listing. Then click Post Next to post them one by one.

<img width="280" alt="Dump Truck panel" src="https://github.com/user-attachments/assets/e9dcb1fc-288f-43e0-9a2b-4c579d16a74a" />

Bind `/click DumpTruckPostButton` to a key to spam through the list.
